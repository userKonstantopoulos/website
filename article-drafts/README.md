# Επιστημονικά άρθρα — διαδικασία έγκρισης

Τα άρθρα δημιουργούνται αρχικά ως προσχέδια στο `article-drafts/`. Δεν δημοσιεύονται αυτόματα.

## Κριτήρια
- Θέμα σχετικό με λογοθεραπεία και τις υπηρεσίες του κέντρου.
- Ακριβείς, επαληθεύσιμες επιστημονικές πηγές· καμία επινοημένη παραπομπή.
- Χωρίς εξατομικευμένες διαγνώσεις ή υποσχέσεις θεραπευτικού αποτελέσματος.
- Σαφής τίτλος SEO, meta description και φυσική αναφορά στην τοπική περιοχή μόνο όπου είναι ουσιαστική.
- Έλεγχος διπλοτυπίας με τις υπάρχουσες σελίδες.
- Ρητή έγκριση του επιστημονικά υπευθύνου πριν από μεταφορά στον δημόσιο ιστότοπο.

## Διαδικασία
1. Η AI δημιουργεί πρόταση άρθρου ως αρχείο Markdown στον φάκελο `article-drafts/`, με ενότητα «Πηγές προς επαλήθευση».
2. Δημιουργείται draft Pull Request για αξιολόγηση. Η δημιουργία του PR **δεν** δημοσιεύει άρθρο.
3. Μετά από επιστημονική έγκριση, το άρθρο μετατρέπεται σε HTML και προστίθεται η σύνδεσή του από τις σχετικές σελίδες και το sitemap.
4. Γίνεται τεχνικός έλεγχος και μόνο μετά από νέα έγκριση γίνεται merge στο `main`.

## Αυτοματοποιημένη παραγωγή
Η παραγωγή προσχεδίων ενεργοποιείται μόνο χειροκίνητα από GitHub Actions (`Generate article draft for approval`). Απαιτεί το GitHub Actions secret `OPENAI_API_KEY`. Κανένα προσχέδιο δεν δημοσιεύεται αυτόματα. Η δημιουργία περιεχομένου μέσω AI δεν ισοδυναμεί με βιβλιογραφική έρευνα: οι πηγές και οι κλινικοί ισχυρισμοί επαληθεύονται ανεξάρτητα πριν από οποιαδήποτε δημοσίευση. Το κόστος αφαιρείται από το υπόλοιπο OpenAI API.
